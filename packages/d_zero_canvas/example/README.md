# ⚡️ d_zero_canvas Massive Elements Benchmark App

Compares `d_zero_canvas` (`ZDanmaku`, `ZInfiniteGrid`, `ZFreehandCanvas`) against traditional `Stack` + `Positioned` + `Text` trees under high-frequency bullet-comment and pan/zoom stress.

## 📊 Live Metrics Displayed
- **FPS & Frame Histogram** (`ZFPSMonitor`)
- **CPU Load (%)** (`ZPriceTicker`)
- **RSS Memory / Peak MB** (`ZPriceTicker`)
- **D-Zero vs Traditional Rebuilds & Allocations** (`ZCounter`)

```bash
flutter run
```
