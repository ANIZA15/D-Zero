# d_zero_sensor

Zero-allocation camera & sensor HUD widgets for Flutter & Impeller:
- `ZBarcodeScanner` (`ZCameraPreview`) & `ZeroDetectionController`: SoA bounding-box overlay with animated scan line and `ZeroNumberPainter` confidence percentage.
- `ZCompass`: Cached `ui.Picture` compass dial with `ZeroNumberPainter` degree readout.
- `ZLeveler` & `ZeroTiltController`: 2D spirit bubble leveler with live pitch/roll degree readouts.
