# ⚡️ d_zero_ui Controls Benchmark App

Compares `d_zero_ui` (`ZCard`, `ZBadge`, `ZButton`, `ZSwitch`, `ZSlider`, `ZRangeSlider`, `ZGauge`, `ZKnob`, `ZJoystick`, `ZMarquee`, `ZTypewriterText`, `ZLinearProgress`, `ZCircularProgress`) against traditional Flutter Material controls under continuous 120Hz state modulation.

## 📊 Live Metrics Displayed
- **FPS & Frame Histogram** (`ZFPSMonitor`)
- **CPU Load (%)** (`ZPriceTicker`)
- **RSS Memory / Peak MB** (`ZPriceTicker`)
- **D-Zero vs Traditional Rebuilds & Allocations** (`ZCounter`)

```bash
flutter run
```
