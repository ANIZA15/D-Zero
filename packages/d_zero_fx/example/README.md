# ⚡️ d_zero_fx Visual Effects Benchmark App

Compares `d_zero_fx` (`ZShimmer`, `ZBlur`, `ZRipple`, `ZLiquidProgress`) against traditional `BackdropFilter` (`saveLayer`) and `CircularProgressIndicator`.

## 📊 Live Metrics Displayed
- **FPS & Frame Histogram** (`ZFPSMonitor`)
- **CPU Load (%)** (`ZPriceTicker`)
- **RSS Memory / Peak MB** (`ZPriceTicker`)
- **D-Zero vs Traditional Rebuilds & Allocations** (`ZCounter`)

```bash
flutter run
```
